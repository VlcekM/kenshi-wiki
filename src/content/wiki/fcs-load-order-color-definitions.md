When editing a mod with the "**[Forgotten Construction Set](/forgotten-construction-set)**" you may encounter one of these colour properties

-   **Red**: item has been deleted in a previous mod

-   **Blue**: the _active_ mod in **FCS** has changed the item

-   **Green**: a new item the _active_ mod in **FCS** has added

-   **Orange**: an item added by a _later_ mod in the load order

-   **Grey**: a previously added item that has been deleted by the **FCS** _active_ mod

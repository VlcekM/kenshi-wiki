This character has the "Npc Shek Warrior - Base 1" dialogue package. They have a set "Random" [Personality](/personality), so these personalities are common: Honorable, Traitorous, Smart, Dumb, Brave, Fearful, and Maniacal. If this character manages to join the player faction, they will have the "Player SHEK Warrior" dialogue package.

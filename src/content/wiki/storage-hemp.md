The **Storage: Hemp** is a [storage](/storage) container which exclusively contains [Hemp](/hemp). Players can construct this building after researching [Hemp Farming (Tech)](/hemp-farming-tech).

This container can hold a total of 250 items.

## Trivia

-   When this storage container was introduced in version 0.67.0, it used to look like the storage building for Stones.

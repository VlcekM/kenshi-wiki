**Storage: Leather** is a [storage](/storage) container which exclusively contains [Leather](/leather). Players can construct this building after researching [Storage Boxes: Crafting](/storage-boxes-crafting).

This container can hold a total of 50 [Leather](/leather).

## History

This storage container was introduced in version 0.67.0 and it initially shared the exact same model in-game as [Storage: Chainmail](/storage-chainmail) and [Storage: Armour Plate](/storage-armour-plate).

## Outpost Type IV

## Details

### **Estimated Time**

4 Hours

### **Tech Level**

4

### **Costs**

2 [Engineering Research](/engineering-research)

### **Requirements**

Outpost Type III, [Heavy Building Foundations](/heavy-building-foundations-tech)

## Results

### **New Building(s)**

[Outpost s-IV](/outpost-s-iv)

**Outpost Type Tech** allows the player to build Outpost Type structures, [Outpost s-III](/outpost-s-iii) and [Outpost s-IV](/outpost-s-iv). This tech is **not** available with the [Research Bench](/research-bench) only: you must obtain [Advanced Outpost Blueprints](/blueprints) and use it to unlock this research tree.

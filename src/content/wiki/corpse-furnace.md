A **Corpse Furnace** is a [building](/buildings-list) which can be used to dispose of dead characters. Corpse Furnaces are found in the [power](/power) category in the Build Mode menu. It can be built after players research [Corpse Disposal](/corpse-disposal).

Characters which are carrying a corpse can use this machine to destroy the corpse as well as all items which were held by the corpse.

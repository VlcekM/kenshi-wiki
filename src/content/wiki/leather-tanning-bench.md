The **Leather Tanning Bench** is a crafting building type introduced in version 0.67.0. This crafting station allows players to craft [Leather](/leather), which is used by the [Leather Armour Crafting Bench](/leather-armour-crafting-bench).

The Leather Tanning Bench uses [Animal Skin](/animal-skin) to create [Leather](/leather). It is unlocked with the [Leather Armour Crafting](/leather-armour-crafting) Research.

Using the Leather Tanning Bench improves the [Armour Smith](/armour-smith) skill.

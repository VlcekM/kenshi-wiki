**Storage: Chainmail** is a [storage](/storage) container which exclusively contains [Chainmail Sheets](/chainmail-sheets). Players can construct this building after researching [Storage Boxes: Crafting](/storage-boxes-crafting). It is the only type of storage of industrial materials that must be placed **inside** a building. This is perhaps an oversight or a tribute to the delicate nature of the chainmail.

This container can hold a total of 25 [Chainmail Sheets](/chainmail-sheets).

## History

This storage container was introduced in version 0.67.0. It shares the exact same model in-game as [Storage: Armour Plate](/storage-armour-plate). When it was added, [Storage: Leather](/storage-leather) also shared the same model.
